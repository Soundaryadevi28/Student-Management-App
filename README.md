# Student Management App

A professional CLI application built with **Python** and **MySQL** to manage student records efficiently using **Object-Oriented Programming (OOP)** principles.

### 🚀 Features
* **Add New Records:** Store student details including ID, Name, Age, Course, and Grade.
* **View Records:** Fetch and display all stored records from the MySQL database.
* **Delete Records:** Remove specific student entries using their unique ID.
* **Data Persistence:** Uses a relational database so data is saved even after the program closes.

### 🛠️ Technical Stack
* **Language:** Python 3.x
* **Database:** MySQL
* **Library:** `mysql-connector-python`

### 📋 Setup Instructions
1. **Database:** Execute the commands in `database_setup.sql` in your MySQL Workbench to create the database and table.
2. **Environment:** Install the required library using:
   ```bash
